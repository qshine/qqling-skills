# Text-poster mode

Read this reference when no real-person photo is supplied.

Make the viewpoint the protagonist. Do not generate a generic synthetic presenter to fill the frame.

## Choose one supporting visual device

Select a device that clarifies the source:

- a concrete object central to the article;
- a simple scene that demonstrates the problem or payoff;
- one diagram-like relationship, such as a contrast, sequence, or bottleneck;
- restrained icons, warning marks, arrows, checkboxes, or hand-drawn annotations;
- blank torn-paper, notebook, tape, grid, or label surfaces prepared for exact copy later.

The visual device should explain or amplify the claim. Remove decoration that could be swapped into any unrelated post without changing its meaning.

## Layout

- Give the headline the largest area and strongest contrast.
- Use one metaphor object or one diagram cluster, not several competing scenes.
- Keep 15–25% of the canvas visually quiet.
- Establish a clear top-to-bottom or diagonal reading path.
- Keep generated surfaces free of pseudo-text. Add every meaningful character with the compositor.

Pure typography is a valid outcome when an object or scene would dilute the idea.
