## 决策与风险

- 取证器仍不执行 Git 或项目命令；预览/应用为了绑定分支、提交与 index，使用固定白名单的本地 Git 元数据查询，禁用可执行扩展。不查询远端或读取凭据。
- 生成内容由 Agent 依据所选控制和现有证据拟定；Python 不用固定模板制造“已满足”。脚本只做确定性安全边界、指标和变更事务。
- 首版自动应用仅新建/追加，既有字节保留；需要删除/重写旧规则的冲突给出人工方案，不能用追加掩盖冲突。
- 验证默认 UTF-8/JSON/Python AST 静态检查；项目级测试必须在最终预览列明，由 Agent 在确认授权范围内执行，结果如实记录。
- 全量扫描有预算，无法完整建立基线时不自动应用。事务不是跨文件原子事务；并发写入/IO异常必须报告部分状态，不自动删除或回滚用户文件。
- Schema/来源版本由控制目录定义；新增接口只能单向消费，不改变六状态、覆盖率和成熟度语义。

## 交付边界

实现整个可调用 Skill，但不安装到用户全局目录、不推送、不合并。安全回归使用临时仓库；不对真实业务仓库执行补强。实际用户确认仍发生在 Skill 使用时的最终文件预览之后。
