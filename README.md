# qqling-skills

## Skills

### skill-usage-auditor

统计 Codex Skill 的实际加载次数，提供周期排行、趋势可视化、覆盖状态和安全的清理建议。普通文本中的 Skill 名称或 `$skill-name` 提及不会被计入使用次数。

### xhs-cover-director

从小红书帖子或文章中提炼高点击潜力标题，结合可选真人照片生成一张可直接发布的 3:4 创意封面。支持真人保真修图、无人物观点拼贴和确定性中文排版，避免生成式文字错字。

## 安装

将 `<skill-name>` 替换为需要安装的 Skill 名称：

```bash
npx skills add qshine/qqling-skills --skill <skill-name>
```
