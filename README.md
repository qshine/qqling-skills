# qqling-skills

## Skills

### skill-usage-auditor

统计 Codex Skill 的实际加载次数，提供周期排行、趋势可视化、覆盖状态和安全的清理建议。普通文本中的 Skill 名称或 `$skill-name` 提及不会被计入使用次数。

### xhs-cover-director

从小红书帖子或文章中提炼高点击潜力文案，可生成一张可直接发布的 3:4 创意封面，或生成总计 1–5 张的 9:16 系列图文海报及 300 字以内发布文案。支持手绘、黑黄警示、温暖个人 IP、米色手账风格，结合可选真人照片和确定性中文、emoji 排版，避免生成式文字错字。

### schedule-night-shifts

根据人员、月份、请假和个人要求生成科室夜班 Excel 排班表，支持中国法定节假日、跨月公平账本、候选方案确认和临时请假后的最小改动修复。

## 安装

将 `<skill-name>` 替换为需要安装的 Skill 名称：

```bash
npx skills add qshine/qqling-skills --skill <skill-name>
```
