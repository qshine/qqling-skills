# 小红书封面导演

## Problem Statement

如何让个人内容创作者只提供一篇帖子或文章，以及一张可选的真人照片，就能获得一张标题有点击欲、中文完全准确、人物真实自然、可以直接发布的小红书封面？

## Recommended Direction

构建一个“编辑判断 + 视觉生成 + 精确排版”的混合式 Skill。它先理解内容并在内部选择最强标题，再根据是否存在真人照片进入真人 IP 或无人物观点海报模式。图片模型只生成不含文字的视觉底图，最终中文由确定性工具排版。

用户只收到一张综合最优的 3:4 成品，不需要在多张半成品之间选择。

## Key Assumptions to Validate

- [ ] 独立排版层能够实现关键中文字符 100% 准确，并保持专业断行与层级。
- [ ] 人物处理能够增强封面冲击力，同时保留本人身份、表情和姿态。
- [ ] 内部标题评分比直接摘要更能兼顾内容准确性与点击动机。
- [ ] 用户接受只收到一张最佳结果，十次真实任务中至少七次无需重新设计。

## MVP Scope

- 从一篇帖子、文章或口播稿提炼核心观点。
- 内部生成并评分 3–5 个标题，只保留最佳标题。
- 支持真人照片和无人物观点海报两种模式。
- 支持黑黄警告、暖色个人 IP、米色手账拼贴三类视觉语言。
- 生成不含文字的底图，再用确定性工具排版中文。
- 默认输出一张 1080×1440 封面，强制校验 3:4 比例、安全区、错字、人物、构图和缩略图表现。

## Not Doing

- 一次输出多张候选图——用户明确需要一张完成度最高的成品。
- 生成完整小红书正文——第一版只负责封面。
- 承诺真实点击率——账号、选题和受众数据不在 Skill 控制范围内。
- 长期学习个人风格——先验证单张成品质量。
- 大型模板库——模板数量不能替代内容判断。
- 精确复刻参考作品——只提取高层视觉属性。
- 默认生成虚拟人物——无真人图时让观点和物件成为主角。
- 批量生成和自动发布——不属于第一版核心价值。

## Open Questions

- 第一版应推荐哪些可商用中文字体？
- 标题吸引力评分是否需要结合实际发布数据持续校准？
- 人物保真检查是否需要更明确的相似度指标？
- 用户是否需要一次“更克制”或“更有冲击力”的定向重做机会？
